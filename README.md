# Customer_behavior_analysis
Data anlaytics project showcasing customer behavior analysis using Python, SQL and PowerBI


Data Analytics End-to-End Project

Overview

This project demonstrates a complete **Data Analytics workflow** starting from raw dataset processing to business insights generation. The project covers **data loading using Python, Exploratory Data Analysis (EDA), data cleaning, SQL analysis, Power BI dashboard development, report preparation, and presentation creation using Gamma**.

The objective is to transform raw data into meaningful insights and present them in a professional and business-oriented format.

## How to Run

### Clone Repository

```bash
git clone <repository-url>
cd Data-Analytics-Project
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Jupyter Notebook

```bash
jupyter notebook
```

### Execute SQL Queries

* Import dataset into PostgreSQL / MySQL / SQL Server
* Run queries from `sql_queries/`

### Open Dashboard

* Launch `.pbix` file in Power BI Desktop
